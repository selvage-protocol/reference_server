Selvage demo

Terms of use

This is a small public demo of Selvage, enough for you and a friend to try it together. It is not a service, and it is free for personal and evaluation use.

This instance is for non-commercial use only.

Rooms are not persisted. They are held in memory, and they may be reset at any time.

For commercial work, self-host it. The server is the same one this demo runs.

This instance and the software

This page is the notice of this one running instance. It changes nothing about what anyone may build with Selvage, and the licences are unchanged:

  • The Rust workspace and the clients are MIT OR Apache-2.0.
  • The server binary, crates/selvaged, is source-available under FSL-1.1-MIT.
  • The specification is CC-BY-4.0.

Where the code is

The project lives at github.com/selvage-protocol: the server, the VS Code client, the Neovim client, the browser client, and the specification. The site is selvage-protocol.vercel.app.
